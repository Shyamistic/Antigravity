# Antigravity Production Architecture

This document outlines the end-to-end production-grade implementation of the Antigravity Institutional Liquidity Orchestrator.

## 1. System Overview
Antigravity is a decentralized treasury management system for institutions. It bridges off-chain compliance (VASP-to-VASP) and traditional banking (SDP/ACH) with on-chain liquidity (Solana Token-2022).

### 🏗️ 3-Tier Architecture
1.  **Frontend (React/Vite)**: Institutional Dashboard providing real-time visibility and manual override controls.
2.  **Orchestration Gateways (Node.js/Express)**:
    *   **Compliance Gateway**: Handles IVMS 101/Travel Rule attestation. Communicates with Chainalysis KYT and generates on-chain attestations for the Transfer Hook.
    *   **SDP Bridge**: Orchestrates USDC/Banking settlement via Modern Treasury/FedNow (simulated).
3.  **Smart Contract Hub (Solana Devnet)**:
    *   **Core Program**: Enforces protocol-level compliance via Token-2022 Transfer Hooks.
    *   **Yield Engine**: Executes CPI (Cross-Program Invocations) to route liquidity from treasury to yield vaults (e.g., Solstice).

## 2. Production Data Flow (Current Implementation)
### Liquidity Sweep
1.  **Monitor**: `antigravity-yield` program monitors the Treasury ATA (Associated Token Account) balance.
2.  **Logic**: If balance exceeds the `idle_threshold` (e.g., $1M), the program calculates the `sweep_amount`.
3.  **Execute**: The Yield Engine invokes a CPI call to the Solstice `YieldVault` to deposit the excess funds.
4.  **Proof**: The transaction is finalized on Solana Devnet and reflected in the Dashboard's **Recent Operations**.

### Compliance Check (Travel Rule)
1.  **Initiate**: Institution A initiates a transfer of $5,000 $AG-USD.
2.  **Intercept**: Solana runtime triggers the `antigravity-core` **Transfer Hook**.
3.  **Verify**: The hook checks for a fresh `ComplianceAttestation` PDA (generated by the Compliance Gateway within the last 400ms).
4.  **Result**: If verified, the transfer succeeds. If not (attestation expired or missing), the transfer is blocked at the protocol level.

## 4. Scalability Note
For high-frequency institutional trading, the Compliance Gateway uses **Transaction Flash-Attestation**: the gateway signs and submits the attestation in the *same* block as the institutional transfer, ensuring 0-latency compliance.
